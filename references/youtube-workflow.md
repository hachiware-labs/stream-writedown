# Computer Use による YouTube 取得

この資料は Computer Use 経路を使うときに読む。内容単位への再構成、校正、翻訳、保存形式は [content-layout.md](content-layout.md) に従う。

## 初期化と操作

`computer-use` の初期化と対象ウィンドウ選択を先に完了する。ブラウザーウィンドウが複数候補になる場合は推測せず、一意に絞る。

1. 最新のスクリーンショットまたはアクセシビリティ情報で観察する。
2. その観察から決めた操作を 1 回だけ行う。
3. 直後に再観察し、表示変化とフォーカスを確認する。
4. ページ遷移、モーダル、パネル開閉、スクロールのたびに繰り返す。

アドレスバーへの入力は対象ブラウザーとフォーカスを確認してから行う。ログイン、年齢確認、CAPTCHA、安全警告を自動操作または回避しない。Computer Use でターミナルやファイル管理を操作しない。

## 一覧の走査

### チャンネル

チャンネル名をヘッダーから取得する。`動画`、`ショート`、`ライブ` に相当する各タブがあれば順番に開き、現在の並び順のまま末尾までスクロールする。仮想化されたカードは見えなくなる前に、動画 ID または URL、タイトル、チャンネル、位置を記録する。

### 再生リスト

再生リスト名、所有者、表示総数があれば記録する。先頭から表示順に収集し、非公開・削除済み項目も位置と表示ラベルを残す。

### 重複と末尾

動画 ID を主キーにし、URL の付加パラメーターは同一性判定に使わない。明示された総数へ到達した場合、末尾表示を確認した場合、または連続する再観察で新しい ID が増えない場合に完了とする。

## 動画ページのメタデータ

概要欄を展開し、動画 ID、タイトル、チャンネル、公開日を読む。一覧カードより動画ページの表示を優先する。公開日は UI が示す暦日だけを `YYYY-MM-DD` へ正規化し、相対日付やタイムゾーンから推測しない。

現在 URL を十分な確度で判定できず Computer Use の安全機構が停止した場合は、古い URL や推測した動画 ID で続行しない。ユーザーが Chrome を明示していなければ、利用可能な Chrome 経路へ切り替えてよい。

## 原字幕キューの取得

`文字起こしを表示` / `Show transcript` が見えない場合は、展開した概要欄、動画のその他メニュー、説明パネルの順に探す。複数トラックがある場合は、ユーザー指定言語、元言語の手動字幕、元言語の自動字幕、表示中の既定字幕の順に選ぶ。勝手に翻訳字幕へ切り替えない。

文字起こしパネルを可能なら上端へ戻し、次の形で収集する。

```json
{"timestamp": "00:05", "text": "表示どおりの発話"}
```

- タイムスタンプと対応テキストを 1 キューとして扱う。
- スクロール境界で同じ `(timestamp, text)` が重なった場合だけ重複除外する。
- 同じ時刻の異なるテキストは両方残す。
- 語順、文字、空白、`[音楽]`、`[拍手]`、`[Music]` などを取得中に直さない。
- UI にない話者ラベル、句読点、内容を補わない。
- タイムスタンプ表示を消さない。

アクセシビリティの文書テキストに全体が含まれる場合も、先頭・末尾と件数増加の停止を確認する。表示範囲だけなら文字起こしパネル内をスクロールする。ページ本体が動いた場合はパネルへフォーカスし直し、最新状態から続ける。

## 原キューの完全性

保存用の区切り直しや校正を始める前に確認する。

- 最初と最後のキューがパネルの先頭・末尾と一致する。
- タイムスタンプが逆行していない。
- スクロール境界以外で重複していない。
- 取得キュー数を記録する。
- キューの `text` を表示順に連結し、検証用原文として固定する。

原キューと検証用原文は `.audit.json` に保存し、校正後も変更しない。

## 取得不能と中断

次の場合は回避せず `transcript_status: unavailable` と理由を保存する。

- 文字起こしが提供されていない、または無効
- 動画が非公開、削除済み、地域制限、年齢制限などで閲覧不能
- CAPTCHA、認証、権限要求、安全警告が作業を遮る
- Computer Use の復旧手順後も状態を取得できない

途中までの場合は `transcript_status: partial` とし、取得済みキュー、最後のタイムスタンプ、理由を残す。Computer Use がユーザー操作で停止された場合は追加操作を行わない。
