# YouTube UI 取得・出力リファレンス

この資料は、対象を実際に走査して文字起こしを保存するときに読む。

## Computer Use での取得

`computer-use` の初期化と対象ウィンドウ選択を先に完了する。ブラウザーウィンドウが複数候補になる場合は推測せず、一意に絞れる状態にする。

1. 最新のスクリーンショットまたはアクセシビリティ情報で画面を観察する。
2. その観察から決めた操作を 1 回だけ行う。
3. 直後に再観察し、表示変化とフォーカスを確認する。
4. ページ遷移、モーダル、パネル開閉、スクロールのたびに同じループを繰り返す。

アドレスバーへの URL 入力は、最新観察で対象ブラウザーとフォーカスを確認してから行う。YouTube の Cookie 表示などがあれば必要な範囲だけ処理する。ログインや年齢確認が必要になった場合、認証を自動操作したり回避したりしない。

## 一覧の走査

### チャンネル

チャンネル名をヘッダーから取得する。`動画`、`ショート`、`ライブ` の各タブがあれば順番に開き、現在の並び順のまま末尾までスクロールする。各観察で新しく見えたカードを作業用一覧へ追記する。タブ名がローカライズされていても、表示内容とタブの役割から判断する。

### 再生リスト

再生リスト名、表示される所有者、動画総数があれば記録する。リストの先頭から表示順に収集する。非公開・削除済み項目も位置と表示ラベルを記録し、後から欠落扱いにする。

### 重複と末尾

動画 ID を主キーにする。URL の付加パラメーターは同一性判定に使わない。末尾判定の前に少なくとももう一度観察し、新しい ID が現れないことを確認する。ただし YouTube が明確な総数を表示し、その件数へ到達した場合はそれを優先できる。

## 動画ページ

概要欄を展開してタイトル、チャンネル、公開日を読む。タイトルやチャンネル名は一覧カードより動画ページの表示を優先する。日付は UI が示す暦日だけを `YYYY-MM-DD` へ正規化し、タイムゾーンによる日付変更を勝手に行わない。

`文字起こしを表示` / `Show transcript` が直接見えない場合は、展開した概要欄、動画のその他メニュー、説明パネルの順に探す。UI 文言はロケールや実験表示で変わり得るため、スクリーンショットとアクセシビリティ情報の両方を必要に応じて使う。

文字起こしを開いたら可能なら上端へ戻し、次を守る。

- タイムスタンプと対応テキストを 1 キューとして扱う。
- 同一キューが画面間で重なった場合は `(timestamp, text)` で重複排除する。
- 同じ時刻に異なるテキストがある場合は両方残す。
- `[音楽]`、`[拍手]`、`[Music]` などの非発話表記も残す。
- 話者ラベルは UI に明示された場合だけ残す。
- 読めない箇所を推測で補完しない。
- タイムスタンプ表示を消す設定には切り替えない。

アクセシビリティの文書テキストにパネル全体が含まれる場合も、先頭・末尾と件数の増加停止を確認する。表示範囲だけの場合は文字起こしパネル内をスクロールする。ページ本体が動いてしまったら、パネルへフォーカスし直して最新状態から再開する。

## 取得不能と中断

次の場合は回避を試みず、`transcript_status: unavailable` と理由を保存する。

- 文字起こしが提供されていない、または無効
- 動画が非公開、削除済み、地域制限、年齢制限などで閲覧不能
- CAPTCHA、認証、権限要求、安全警告が作業を遮る
- Computer Use の復旧手順を尽くしても画面状態を取得できない

途中まで取得して継続不能になった場合は `transcript_status: partial` とし、最後に取得できたタイムスタンプと理由を書く。Computer Use がユーザー操作で停止された場合は、追加操作を行わずその時点で中断する。

## Markdown 形式

完全取得時は次の構造を使う。値は必ず YAML として安全に引用する。取得できなかった任意項目は空文字にせず `null` とする。

```markdown
---
title: "動画タイトル"
channel: "チャンネル名"
video_id: "abcdefghijk"
url: "https://www.youtube.com/watch?v=abcdefghijk"
published_date: "2026-08-23"
source_scope: "video"
playlist_name: null
playlist_position: null
transcript_language: "ja"
transcript_kind: "auto"
transcript_status: "complete"
retrieved_at: "2026-08-23T12:34:56+09:00"
---

# 動画タイトル

## 動画情報

- チャンネル: チャンネル名
- 公開日: 2026-08-23
- URL: https://www.youtube.com/watch?v=abcdefghijk
- 文字起こし: ja / 自動生成

## 文字起こし

- `00:00` 発話テキスト
- `00:05` 次の発話テキスト
```

`source_scope` は `video`、`playlist`、`channel` のいずれかにする。`transcript_kind` は UI で確認できた場合だけ `manual` または `auto`、不明なら `unknown`。言語は UI の言語名または確認できた言語コードを一貫して使う。

YouTube が章を明示している場合だけ、文字起こしを次のように章見出しで区切ってよい。

```markdown
### `00:00` 章タイトル

- `00:00` 発話テキスト
```

取得不能時も同じ frontmatter を使い、本文を次の形にする。

```markdown
## 文字起こし

取得できませんでした。

- 状態: unavailable
- 理由: YouTube 上で文字起こしが提供されていない
```

部分取得時は取得済みのキューを残し、その前に状態、停止理由、最終取得タイムスタンプを書く。

## 完全性チェック

保存前に次を確認する。

- ファイルの `video_id` が動画ページの ID と一致する。
- 最初と最後のキューが文字起こしパネルの先頭・末尾と一致する。
- キュー順が UI と一致し、タイムスタンプが逆行していない。
- スクロール境界で生じた完全一致の重複だけが除かれている。
- タイトル、チャンネル、公開日を推測で補っていない。
- `retrieved_at` は取得時点の ISO 8601 で、ローカル UTC オフセットを含む。
